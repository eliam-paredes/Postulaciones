# 50 empresas de desarrollo de software en Santo Domingo, RD

Investigado el 2026-11-07. Fuentes: web de cada empresa, directorios de Clutch (RD), agencypartners.co y búsquedas web.

- **LinkedIn:** solo aparece si la empresa lo enlaza en su web o salió en una búsqueda. "No enlazado" = la web no lo pone. No se adivinó ningún enlace.
- **Apps/proyectos:** los nombres que publica la propia empresa. "No publica" = no muestra portafolio.
- **Aplicar vacante:** página de empleo que carga de verdad. "No tiene" = no hay enlace y las rutas típicas (/empleos, /careers) dan 404.
- **Correo empleo:** solo el correo que la empresa pide para enviar el CV. Si no hay, se pone el de contacto general entre paréntesis, marcado "contacto".
- Etiquetas: [VERIFICADO] leído en su web. [DIRECTORIO] solo de Clutch o terceros (la web no cargó). [OJO] sede principal fuera de RD o no es una software house pura.

## Leyenda de estatus

| Estatus | Qué significa |
|---|---|
| No contactado | Todavía no se ha hecho nada con esta empresa. |
| Correo hecho | El correo o mensaje está escrito y listo, pero no se ha enviado. |
| Enviado | Se mandó el correo o se aplicó por su portal o formulario. |
| Seguimiento | Se envió un segundo mensaje porque no contestaron. |
| Respondió | Contestaron (aunque sea para pedir más datos). |
| Entrevista | Hay entrevista agendada o hecha. |
| Rechazado | Dijeron que no o cerraron el proceso. |
| Descartado | Se decidió no contactarla (no encaja, sin correo, sede fuera, etc.). |

Para cambiar el estatus, edita la última columna de la fila de la empresa.
