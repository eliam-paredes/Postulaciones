## Texto literal de la oferta

En BC Tecnología buscamos un(a) Desarrollador(a) Full Stack Semi Senior para incorporarse a un proyecto donde tendrá la oportunidad de desarrollar y mantener aplicaciones web escalables y seguras, participando activamente tanto en frontend como backend.

El rol contempla el uso de herramientas de Inteligencia Artificial para optimizar procesos de desarrollo, generación y refactorización de código, documentación, testing y resolución de problemas, validando técnicamente las soluciones propuestas por estas herramientas.

Find this job and more on Get on Board.

Principales responsabilidades
- Desarrollar y mantener funcionalidades frontend utilizando React.js y TypeScript.
- Implementar servicios backend y APIs utilizando Node.js.
- Diseñar, desarrollar y consumir APIs RESTful.
- Trabajar con bases de datos NoSQL, principalmente MongoDB.
- Aplicar buenas prácticas de desarrollo, seguridad, autenticación y calidad de código.
- Participar en procesos de integración y despliegue continuo (CI/CD).
- Utilizar herramientas de IA como apoyo en codificación, refactorización, debugging, documentación y testing.
- Validar técnicamente las respuestas y el código generado por herramientas de Inteligencia Artificial.
- Colaborar con equipos de desarrollo, producto y otras áreas involucradas.

Requisitos técnicos
- Experiencia intermedia en React.js, TypeScript y Node.js.
- Conocimientos en APIs RESTful y MongoDB.
- Manejo de Git y Docker.
- Experiencia o conocimientos en procesos de CI/CD.
- Conocimientos básicos de seguridad de software y buenas prácticas OWASP.
- Familiaridad con servicios Cloud como AWS o Google Cloud Platform.
- Experiencia práctica utilizando herramientas de IA para desarrollo, tales como GitHub Copilot, ChatGPT, Claude, Cursor o similares.
- Conocimientos básicos de prompts, embeddings, vectorización, búsqueda semántica y RAG.

Conocimientos deseables
- GraphQL y Redis.
- Arquitecturas orientadas a eventos.
- Mensajería y procesamiento asíncrono.
- Integración de APIs de modelos de lenguaje (LLM).
- Experiencia incorporando funcionalidades de Inteligencia Artificial en aplicaciones.
