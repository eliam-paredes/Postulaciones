# Plantillas por situación

Son estructuras, no textos para copiar. Rellena siempre con datos reales.
Adaptado de cold-message-writer/references/templates.md (felixleezd, MIT).
`[ ]` = dato real obligatorio.

## Empleo

### Al hiring manager (después de aplicar o en vez de aplicar)
```
asunto: [tema concreto de su equipo/producto], en minúsculas

[gancho sobre ellos: algo que lanzaron / publicaron / el puesto y el problema que revela].
[una prueba concreta del CV maestro conectada a ese problema].
[petición pequeña: ¿te mando el demo / el enlace al proyecto?]
```
< 90 palabras. Nada de "adjunto mi CV" en la primera línea.

### Al reclutador
```
[puesto exacto + dónde lo vio].
[1 línea: por qué encaja, con el must-have principal y una prueba].
[petición pequeña: ¿sigue abierto? / ¿a quién le envío el CV?]
```

### Después de una entrevista
```
[algo concreto que se habló].
[un aporte nuevo: idea, enlace, mini demo relacionada].
[sin petición, o una muy pequeña].
```

## Clientes (freelance / servicios de IA)

### Con prueba de demanda
```
[gancho sobre su negocio].
[prueba pequeña: "hice lo mismo para [tipo de cliente] y [resultado real]"].
[petición: "¿te paso un ejemplo de 90 s?"]
```

### Sin prueba todavía
```
[gancho sobre su negocio].
[observación específica de su web/producto: el problema que ves].
[oferta de muestra gratis: "te hago [cosa pequeña] gratis para que veas cómo quedaría"].
[pregunta fácil].
```

### Interactuó con un post / contenido
```
[referencia a su interacción concreta].
[conexión con lo que ofreces].
[petición mínima].
```

### Presentación por un contacto común
```
asunto: [nombre del contacto] me sugirió escribirte
[por qué el contacto pensó en ellos].
[qué ofreces en una línea].
[petición mínima].
```

## Secuencia de seguimiento (si no contestan)
1. **Día 3-4 · algo nuevo:** un dato, una idea o una mini demo relacionada. Nunca "solo subo esto".
2. **Día 7-8 · salida fácil:** "si no es prioridad ahora, dímelo y no insisto".
3. **Día 14 · cierre:** "cierro el tema por mi parte; si cambia algo, aquí estoy". Suele ser el que más respuestas trae.
Máximo 3 seguimientos. Cada uno más corto que el anterior.

## Canal
- **LinkedIn:** solicitud de conexión sin nota; espera a que acepte y unos días antes del primer mensaje. La primera línea es la vista previa.
- **Email:** asunto corto en minúsculas, < 90 palabras, una petición.
- **X:** 2-4 líneas, minúsculas, aprovecha el contexto previo.
